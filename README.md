# Fieldwork Garden Studio

A clearly fictional business website for HyperSEO live acceptance testing.

The JSON files in `content/` are the reviewed source. `npm run build` creates the static site in `docs/`. `npm test` validates the source and generated pages. GitHub Pages publishes the result after an approved change reaches `main`.

All business details are fictional. The site collects no personal information and offers no bookings or payments.
